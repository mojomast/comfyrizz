# Comfyrizz

Open-source AI motion graphics and explainer videos: describe a talk, launch or lesson in chat and get a 30–90 s motion-graphics video with exact type, charts, generated vector art, FLUX 3 Klein images, LTX-2.5 looping plates and Kokoro narration. GPU work runs on a Google Colab VM the app starts and stops for you, or on your own ComfyUI. Built for Comfy's Open Source Higgsfield hackathon.

**Status: pre-alpha scaffold (Oct 17, 2026).** Nothing runs yet.

- Spec: [docs/SPEC.md](docs/SPEC.md)
- Plan and ownership: [docs/PLAN.md](docs/PLAN.md), task briefs in [docs/tasks/](docs/tasks/)

Quickstart, backends, LLM setup and known limits: coming with M1 (CPU vertical slice).
