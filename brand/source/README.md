# Comfyrizz brand source (Kinetic ZZ, pack v1)

- `approved-concept.png`: the approved concept, preserved unchanged (source of truth for the visual direction).
- `*-ref.png`: downscaled, palette-reduced copies of the generated raster derivatives (logo light/dark/mono, symbol, social cover). Reference only; never embed them in an SVG master.
- `brand-tokens.css` / `brand-tokens.json`: proposed palette and layout tokens. `palette-contrast.json`: WCAG ratios for token pairs.
- `brand-guide.txt`, `AGENT-BRIEF.txt`: identity guidance and the refinement brief. `asset-manifest.json`: the original full-size files' dimensions and sha256.

No fonts, model weights or third-party logo assets are included. The SVG masters and exports live in `brand/` (built in the BRAND tasks).
