# Motion styles guide (MOTION-UPGRADE M19)

User/judge guide to the 24 named motion looks, the effects/transitions catalogs, the asset licences, and the look score. Source files all live in `scripts/motionkit/`. Specs: `docs/specs/MOTION_UPGRADE.md` and `docs/research/MOTION_RESEARCH.md`.

Two layers of output, and it matters what a judge can see **today**:

- **Tier A — visible today (no renderer change):** each look compiles to fields the package schema already accepts — `brand.palette`, `brand.fonts`, per-scene `motion` (energy, entry, ease/spring, emphasis, `transitionOut`, `recipe`) and `background.procedural.pattern`. Compiled packages pass `validatePackage` and `motion_lint` untouched.
- **Tier B — after M17 (`needs-kyle-ok`, gated):** a `comfyrizz.look/v1` sidecar carries the finishing stack, font files and GL/overlay transition hints. Renderers that ignore the sidecar still render tier A; mounting the finishing `LookLayer` in the renderer is the gated part (`apps/renderer/src/look-layer.tsx`).

## How the agent picks and varies looks

The agent skill is `packages/agent/src/skills/motion-style/SKILL.md` (bundled, registered in `BUNDLED_SKILL_IDS` in `packages/agent/src/skills/index.ts`), backed by three tools in `packages/agent/src/tools.ts` and `packages/agent/src/style-recipes.ts`:

- **`style.list`** — returns a one-line-per-recipe catalog card (≤ 120 chars/line) via `cards.mjs` `catalogCard()`, plus per-recipe cards (≤ 1400 chars) via `recipeCard()` injected only for the chosen look.
- **`style.suggest({tone, goal, history})`** — runs `variety.mjs` `pickRecipe(recipes, {tone, goal, energy, history, seed})` with a seeded weighted sample (mulberry32; a given seed reproduces the pick) and returns three ids with reasons.
- **`style.apply({recipeId, seed})`** — runs `compile.mjs` `compileRecipe(pkg, recipe, {seed})` → `{pkg, look}`: the compiled package (tier A) + the `comfyrizz.look/v1` sidecar, then `look-score.mjs` `scoreLook()`.

Variety mechanics (`variety.mjs`, "spec section 7"):

- **Fit score**: tone affinity (playful / serious / moody / energetic tables) + goal affinity (explain, story, promo, brand) + energy match, each weighted 0.3 / 0.3 / 0.2 on a 0.5 base.
- **Anti-repetition**: `findRecentHistoryPenalty` penalises any recipe within `recipeDistance` < 0.35 of any of the last 8 history entries; the last 4 picked ids are effectively forbidden (`weight ≈ 1e-6`). History is plain JSON kept per user session by the server/agent; the motionkit functions never store it. `recipeDistance` is taxonomy + palette distance (0–1).
- **Inside a film**: `sceneVariation(recipe, scenes, seed)` rotates entries/emphasis across scenes so no three consecutive scenes share an entry and exactly one hero scene exists. One recipe per film; the primary transition covers most cuts with accents elsewhere, and primary + accent transitions stay ≤ 3 types, each inside the recipe's energy family, so `motion_lint` passes without warnings.
- Do / don't in a recipe keep the agent honest ("flush-left headlines", "never centred text", etc.); recompile around a recipe instead of hand-editing compiled fields.

## Effects catalog

`scripts/motionkit/data/effects.json` (schema `comfyrizz.effects/v1`) holds 37 effects, each `{id, label, family, params{min,max,default}, cost: css|svg|webgl, cpuFallback, source, license, notes}`. APIs: `loadEffects()`, `getEffect(id)`, `selectEffects({family, cost})`, `listFamilies()`, `validateEffects()` (`effects.mjs`).

**What is visible today versus after M17** — the tier distinction:

- **Visible today (tier A)**: the SVG style frame (built by `styleFrame()` for the gallery and the agent's catalog) renders background pattern, palette, type and a CSS/SVG version of the *first* finish effect (`style-frame.mjs` `FINISH_KIND_BY_ID`). All `cost: css` and `cost: svg` effects can render this way — grain/texture (`feTurbulence`-based), vignettes, scanlines, duotone/grade (`feColorMatrix`), chroma shift, halftone, shadows, glow. The gallery cards show this first-effect render.
- **Visible today (tier B target, gated)**: the full finishing stack for any look — every effect, the whole finish chain per scene, animated grain seed, camera effects (`push-in`, `drift`, `parallax-layers`, `rack-focus`), `motion-smear` and `depth-blur` in time — mounts in the renderer as the LookLayer only after M17 (`needs-kyle-ok`). Until then the sidecar (`comfyrizz.look/v1`) is valid data with an inert renderer.
- **WebGL-only costs, engineered with fallbacks**: `crt-curve` and `lut` are `cost: webgl` and each carries a `cpuFallback` id (`scanlines`, `svg` `feComponentTransfer` approximation) — the fallback renders today; the exact WebGL version is gated, as are the vendored MIT shader implementations (gl-transitions, webgl-noise, glsl-film-grain — see shader rows in `assets.json`).

## Asset licences and fetching

Manifest: `scripts/motionkit/data/assets.json`, guarded by `assets.mjs` `validateManifest()` (SPDX allowlist `[MIT, ISC, CC0-1.0, OFL-1.1]` only; https-only sources; vendored items carry a sha256 or `sha256: null` for fetch-on-demand) and `listLicenses()` for NOTICE generation.

| Category | id(s) | Licence | Vendor strategy |
|---|---|---|---|
| font (16 in manifest) | inter, jetbrains-mono (vendored, already shipped by the renderer); space-grotesk, playfair-display, fraunces, dm-serif-display, archivo-black, bebas-neue, ibm-plex-mono, instrument-serif, syne, press-start-2p, caveat, orbitron, unbounded, vt323 | OFL-1.1 | vendored for the two bundled families; fetch-on-demand for the rest |
| icons | phosphor-icons, tabler-icons, lucide | MIT, MIT, ISC | phosphor/tabler vendored subsets with LICENSE + sha256; lucide fetch-on-demand |
| sfx | kenney-interface-sounds (vendored), kenney-ui-audio | CC0-1.0 | vendored subset (click/whoosh/pop OGG with sha256) / fetch-on-demand |
| texture | polyhaven-ambientcg-textures (paper.jpg, concrete.jpg) | CC0-1.0 | fetch-on-demand (1K JPG) |
| shader | gl-transitions (burn.glsl, fade.glsl, wipe.glsl), webgl-noise, glsl-film-grain | MIT | vendored with sha256; gl-transitions are vendored only where the per-file header says MIT |

Fetch command (data + manifest injected as dependencies; no network in tests; cache paths under a temp dir under `assets/motionkit/`, gitignored via the `assets/motionkit/cache/` line in `.gitignore`):

```sh
# plan only (writes nothing, uses no network)
node scripts/motionkit/fetch-assets.mjs --dry-run

# restrict to one kind (font | icons | sfx | texture | shader)
node scripts/motionkit/fetch-assets.mjs --only font --dry-run

# fetch all allowlisted assets with their licences
node scripts/motionkit/fetch-assets.mjs
```

What it writes into `assets/motionkit/<kind>/<id>/`: the manifest's files, a `LICENSE` alongside each asset (attribution header + the licence text where the manifest names one), `lock.json` (version 1, per-file sha256 — computed where the manifest left `sha256: null`), and the combined `assets/motionkit/NOTICE.txt` grouped by licence. Behaviour: sha256 mismatch (an item carries an expected hash and the bytes differ) exits non-zero and keeps nothing; any licence outside the allowlist is refused before any download; unsafe manifest file names are refused. Excluded licence families (never vendorable): LYGIA (Prosperity), LottieFiles Simple License, post-2019 Pixabay, non-CC0 Freesound, Enchanted Media overlays, LTX-2.x.

The 24 gallery cards each carry a `licences` array (subset of the allowlist) in `docs/motion-gallery/gallery.json`, and the gallery footer states the allowlist.

## Look score

`look-score.mjs` `scoreLook(pkg, recipe, {frameQa})` → `{score, parts, ratios, findings[]}`, 0–100 with weighted parts: adherence 30, rhythm 20, variety 15, contrast 20, finish 5, qa 10 (`LOOK_SCORE_WEIGHTS`). Below `LOOK_SCORE_REVISION_THRESHOLD` = 70 the agent revises the scenes the findings name, using the existing critique loop. Frame-qa remains the hard gate for black/static/flash/safe-area/contrast frames; a report (`apps/renderer/scripts/frame-qa.mjs` `runQa` shape, read-only) deducts `QA_DEDUCTION` = error 4 / warning 2 from the qa part. Contrast uses WCAG (primary vs background ≥ 4.5, secondary ≥ 3, full marks at 7:1). Gallery and recipes-a/b tests assert every demo look compiles and scores ≥ 80.

## ComfyUI-side quality manifest (runtime only)

`scripts/motionkit/data/comfy-workflows.json` (schema `comfyrizz.comfy-workflows/v1`) records the machinery used *at runtime* inside the Google Colab boundary — that execution is mojo-opencode's, not this feature's: RIFE 4.25 (MIT, 2× interpolation), FILM (Apache-2.0), Depth Anything V2 Small (Apache-2.0 depth for parallax), LTX-Video 0.9 / AnimateDiff motion-control, and per-recipe prompt/LoRA hints. Anything whose licence is not vendorable (MIT/ISC/CC0-1.0/OFL-1.1) is `runtimeOnly: true, vendor: false`; LTX-2.x is flagged restricted; the validator refuses secrets, plain `http://` URLs and any Google Colab or notebook wiring in the manifest.
