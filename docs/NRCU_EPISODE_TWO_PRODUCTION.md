## Helpers and resumption

`scripts/demos/nrcu-episode2.py` authors a fresh external production directory
using the original pilot and rock-recut roots. It requires the Witcheer and
Sidbin source sheets in `refs/source/`, the existing pilot artifacts, and the
local Kokoro model cache. It refuses to overwrite an existing `film.json`.

`scripts/demos/nrcu-run.py --session nrcu-episode2` selects the allocated session
for generation and collection; allocation and runtime setup remain separate.
Keep a bounded stop timer and reconcile usage against the 12-credit ceiling.

Once all selected takes have passed review:

1. Run `nrcu-pilot-finish.py finish ROOT --plan-only` to calculate frame-exact
   timing while protecting dialogue.
2. Run `nrcu-rock-score.py ROOT` using that edit plan and the episode's
   `musicCues` mapping.
3. Run `nrcu-pilot-finish.py finish ROOT` to export the master and compact files.

The episode author supplies `exportStem` and `musicCues`. When resuming an
already-authored production, copy those fields from the current helper into its
`film.json` before scoring/exporting; do not rerun authoring over existing work.
Review full decoding, captions, dialogue, shot endings and normal-speed
audiovisual playback before publishing a finished episode.
