# QUALITY-FIXES: catch story, motion, continuity, editing and caption/sound problems before assembly

Source: `docs/research/MOCKUMENTARY_QUALITY_REVIEW_20261020.md` (commit cd8c11b). Branch `feat/quality-fixes`.

## Goal

The mockumentary pipeline could deliver a technically valid film that contradicts its dialogue. This feature adds **additive** validators and QA passes under `scripts/quality/` (pure `.mjs`, node:test, synthetic fixtures). They run before generation, before assembly, and on the final edit:

| Review fix | Tasks |
|---|---|
| 1. Validate story actions (P0 beat contracts: sandwich, chair, raccoon portrait) | Q01, Q02, Q03 |
| 2. Review motion before assembly (P0 temporal: floating Nell at 04:34–04:38) | Q04, Q05, Q06 |
| 3. Lock recurring assets (P1 raccoon artwork, cardigan, props) | Q07, Q08, Q09 |
| 4. Edit around dialogue (P1 fixed 10 s grid, 86.96 s of trailing padding) | Q10, Q11, Q12 |
| 5. Captions ≤ 20 cps, Foley and deliberate reaction pauses | Q13, Q14, Q15, Q16 |
| Integration and docs | Q17, Q18 |

## Boundaries

- HyperFrames and Google Colab rendering code belongs to another agent. No task edits it, `apps/**` or `packages/**`. Those files are read only, for example `packages/planner/src/measured.ts`, `packages/jobs/src/defaults.mjs` and `scripts/demos/temporal-review.py`.
- No task needs Kyle's approval (`needs-kyle-ok`). Wiring these passes into the Remotion, FFmpeg or Colab render core is deliberately left as a later, gated follow-up.
- A missing review is `not_reviewed`, never `passed`. Model scores and pixel-difference metrics are triage signals only.
- The asset library (Q07) is a pure manifest. It is not the REFERENCE-ASSETS feature's UI or routes, which stay planned.

## Acceptance criteria from the review (feature level)

- The sandwich stays visibly out of reach through "Today I can't reach my sandwich". Q02 flags a prompt that contradicts it, and Q03 blocks assembly on a failed or unreviewed beat.
- The courtroom picture remains the approved raccoon asset across opening and payoff (Q08 ARTWORK_SWAP, Q09 refs with sha256). The closing scene pays off the cardigan (Q08).
- The 04:34–04:38 leak fragment is rejected by temporal review (Q05). Approval needs every receipt axis passed (Q06).
- Allocation keeps all dialogue and exactly 600 s (18000 frames at 30 fps) without a fixed 300-frame grid. At least one setup/reveal/reaction sequence is cut on the joke (Q11). Unexplained dialogue tails over 2 s are flagged, and the fixture reproduces 86.96 s (Q10).
- Every presented caption is ≤ 2 lines × 42 chars and ≤ 20 cps, or it is listed for an explicit edit. Text is never silently shortened (Q13, Q14).
- Foley cues sit on visual events, and music never fills a declared reaction pause (Q15, Q16).

Tiers: simple = free pool (prompt budget ~100k tokens); standard = deepseek-v4.1-flash.

Details:

- **Q01** validateBeat(obj)->{ok,errors[] with JSON paths} for comfyrizz.beat/v1 as review section 3 P0: {beat id, speaker, participants[], dialogueAnchor, requiredProps[] (versioned ids like sandwich_01), before{}, duringLine{}, after?{}, rejectIf[] strings, reviewEvidence[] subset of 'approved first frame'|'action midpoint'|'end frame'}. validateBeatPlan(plan) checks unique beat ids and that every speaker is a participant.
- **Q02** lintShotPlan(beats, shots, script)->findings[{beat,shot,code,message}] run before paying for generation. Codes: ANCHOR_MISSING (dialogueAnchor not found in the speaker's line), STATE_CHANGE_UNLICENSED (duringLine state differs from before without a licensing phrase), PROMPT_CONTRADICTS (a shot's image/action prompt matches a rejectIf phrase or moves a prop the contract keeps 'outside reach'), SPEAKER_UNASSIGNED (speaker not in shot participants, the 02:10 chair gag).
- **Q03** Verdict record {beat, status:'passed'|'failed'|'substituted'|'not_reviewed', evidence[{frame or timestamp, file sha256}], reviewer, method, note}. gateBeats(beats, verdicts)->{ok, blocking[]}: every story-critical beat needs passed or an intentional substitution with a note; passed without cited evidence is invalid; absent verdict = not_reviewed and blocks.
- **Q04** samplePlan({durationS, fps, actionWindows[], everyS=2})->sorted unique frame times: first, action-window starts/midpoints/ends, end, and regular intermediates; ffmpegSampleArgs(input, times, outPattern)->argv array (no shell string) for extraction. Mirrors scripts/demos/temporal-review.py sampling (read only).
- **Q05** reviewTake(take, observations)->{status, failures[]} where observations are per-sample reviewer/vision notes {t, bodyCount, characters[], feetGrounded?, scale?, propHolder?, cameraMove?}. Failures: BODY_COUNT_CHANGE, IDENTITY_CHANGE, SCALE_JUMP (>configurable ratio), UNGROUNDED (feet off floor without a licensed action), PROP_TELEPORT, UNINTENDED_CAMERA. Optional triage signals (flow/pixel diffs) only mark samples for inspection, never pass or fail.
- **Q06** buildReceipt({technical, beats, takes, continuity, captions, listening})->{schema:'comfyrizz.quality-receipt/v1', states:{technical,semantic,temporal,continuity,captionReadability,listeningReview}, reviewedFiles[{path,sha256}], failures[], acceptedExceptions[], selectedTakes[]}. Each state is passed|failed|not_reviewed; approved(receipt) is true only when all are passed or have an accepted exception.
- **Q07** comfyrizz.asset-library/v1: assets[{id, version, kind:'character'|'prop'|'artwork'|'costume'|'set'|'sign', label, file, sha256, approvedBy, notes}]. validateLibrary(), resolveAsset(lib, 'raccoon_portrait@1'), hashFile(path,{fs}) via node:crypto. Distinct from REFERENCE-ASSETS (that feature's UI/routes); this is a pure manifest the QA passes read.
- **Q08** checkLedger(lib, shots)-> findings: each shot declares {characters:{name:{costume}}, props:{id:{holder|location}}, artwork:[ids]} at its cut. Flags COSTUME_NOT_PAID_OFF (script requires a costume change that never appears), ARTWORK_SWAP (a recurring artwork beat uses a different asset id or none), PROP_OWNER_JUMP (holder changes without a beat licensing it). Includes matchPairs(shots, assetId) for opening/payoff side-by-side review lists.
- **Q09** attachRefs(shots, lib)->{shots with refs[{id,version,sha256,role:'composite'|'condition'}], findings[]}: every shot that names a recurring asset gets its approved reference and hash (artwork as a composited surface by default); shots naming a recurring asset with no approved ref -> REF_MISSING. Writes nothing; output is a sidecar JSON the generator can read (see workflows/flux3_klein_ref_edit.api.json, read only).
- **Q10** tailReport(voiceManifest,{sampleRate=24000, flagS=2})->{segments[{id, trailingS, speed}], totalTrailingS, shareOfFilm, flagged[]} using trailingPaddingSamples per segment (review section 7). Flags unexplained tails > flagS unless the segment carries an editorial reason (deliberate pause / silent gag), and speed > 1.0 fitting (chapter 17 at 1.15x).
- **Q11** allocate(utterances, beats, {targetS=600, fps=30})-> shots with integer-frame in/out: durations come from measured utterances plus beat roles (setup, reveal, reaction pause, payoff, action hold with reason) instead of a fixed 300-frame grid; total exactly targetS*fps frames by stretching/shrinking flagged reaction/action holds, never by speeding speech. cutsInsideSpeech(shots, utterances) lists cuts within an utterance; each must carry a reason (b-roll, reaction) or be moved to the nearest boundary.
- **Q12** toDurationsReport(utterances, shots)-> the DurationsReport shape that packages/planner/src/measured.ts measuredFromReport accepts (read it; do NOT edit packages/planner), carrying speaker-tagged utterances, pauses and selected clip ranges in a sidecar keyed by scene id, with timing provenance 'measured'|'estimated' preserved. Test checks the shape against a hand-copied minimal type contract quoted from measured.ts in a comment.
- **Q13** captionMetrics(cues,{maxCps=20, maxLine=42, maxLines=2})->{count, medianChars, maxChars, overCps[], overLength[], maxCps, longestS} using speaker.title()+': '+text over end-start (review section 4/7).
- **Q14** presentCaptions(cues, opts)->cues where every output cue is <= 2 lines of <= 42 chars and <= 20 cps: split at phrase boundaries (punctuation, conjunctions), wrap lines, distribute the measured sentence span proportionally to characters and mark sub-cue timing provenance 'estimated' (never invent word timings); cues that still exceed 20 cps are returned in needsEdit[] for an explicit caption edit, text is never silently shortened. Original timings immutable.
- **Q15** comfyrizz.cue-sheet/v1: stems room_tone|foley|music|dialogue; cues[{id, stem, sound (kettle, brush, bell, ceiling_drip, work_stoppage...), shot, eventFrame, visualEvent, gainDb}], pauses[{id, startFrame, endFrame, reason}]. validateCueSheet() and checkCues(sheet, shots): each foley cue must sit on its shot's declared visual event (+-2 frames), no music cue may fill a declared reaction pause, every scene with a listed sound event has a foley cue (MISSING_FOLEY).
- **Q16** duckingPlan(utterances, pauses, {duckDb=-8, attackMs=80, releaseMs=300, fps=30})->music gain automation points: duck under dialogue, rest (no new notes) inside reaction pauses, restore after. Pure data; also ffmpegVolumeExpr(points) string builder for a separate music stem (no execution).
- **Q17** node scripts/quality/cli.mjs beats|takes|continuity|edit|captions|sound|receipt <production-dir or json> [--json]: runs the passes above on a production folder's JSON (beats, shots, voice-manifest, captions, cue-sheet, library) and prints findings; exit 1 on any blocking finding or not_reviewed critical beat. Test spawns it on the fixtures dir.
- **Q18** How each pass maps to the review's findings (P0 beats, P0 temporal, P1 continuity, P1 editing, captions, sound), the pilot workflow (chair, ControlNet, cloud beats + raccoon match before commissioning the rest), commands, statuses (not_reviewed is not passed), and what still needs a human listening/playback pass or render-core integration.
