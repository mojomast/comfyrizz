Initial planning now disables the transport's automatic immediate retries. It permits one retry only on the first request, only for an explicit `ttft_admission_refused` HTTP 429 with no other output, and only when the provider's message gives a positive delay of at most 30 seconds. It waits the specified delay, reports it in progress, and respects cancellation. Other errors, partial output, missing or longer recommendations, and later turns are not replayed. Provider errors retain their code, HTTP status and message through the agent and API; Super Easy displays the failure and retry progress.

The actual captured `run.mjs` now races the proposal and later outcomes against displayed failures and failed agent responses, uses explicit time limits, waits for attachment and playback conditions instead of fixed sleeps, exits nonzero on failure, and writes new evidence into a timestamped subdirectory so earlier evidence is preserved. It does not automatically cancel or retry ambiguous work.
