## Procedural drawing builder

After storyboard.propose, use storyboard.draw for the first drawing and storyboard.extend_drawing to append a layer or continue into an empty scene. Coordinates are 0..1000 on a stretched 1000-square canvas; frames are scene-local, integers, and each end must be >= start. Use #RRGGBB colors. Elements paint in order: paths draw on; filled polygons, rectangles, circles and text fade in and stay. marker:true shows a moving dot on a path during its animation, not an eraser or pen image. Path erase:true erases only that path, not other elements. Split removable lines into separate paths. No arbitrary code, image input, automatic texture or moving tool is available.

For continuation, finish all source animation by its last frame and end marker paths before that frame. Set source_scene_id only when copying into a different scene without a drawing; inherited visible elements start fully drawn at frame 0, erased paths are omitted. storyboard.inspect_drawing returns zero-based source indices: remove removes an element instantly; erase animates a copied path only. Omit source_scene_id to append to the same scene. The result must contain 1–120 elements total. Hold the final state; inspect early, middle, final and cut frames when visual review is available.

Example (scene s1 has 100 frames): storyboard.draw {"scene_id":"s1","drawing":{"background":"#ffffff","elements":[{"type":"path","points":[[100,100],[300,100]],"color":"#222222","width":3,"start":0,"end":30,"marker":true}]}}. Continue with storyboard.extend_drawing {"scene_id":"s2","source_scene_id":"s1","elements":[{"type":"circle","x":300,"y":100,"radius":12,"color":"#cc4400","start":10,"end":20}]}.

Design actual subject geometry before labels. For solid objects use back walls, top planes, darker vertical faces, contours and details; individual stair treads need risers. Honor the requested medium and contrast with authored strokes and planes. Native drawings and mixed-layout packages need no minimum SVG count. Complete the requested scenes and required referenced assets; plan a still only when the brief calls for one.
