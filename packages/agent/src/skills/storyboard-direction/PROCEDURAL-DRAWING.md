## Procedural drawing builder

These instructions apply only when a scene needs a procedural drawing. Generated footage, product photography and native title layouts do not require drawings. storyboard.inspect_drawing inspects existing drawing elements, not rendered images or video; never call it on a scene without a drawing or create a drawing merely to satisfy inspection.

For a requested drawing, after storyboard.propose use storyboard.draw for the first drawing and storyboard.extend_drawing to append a layer or continue into an empty scene. Coordinates are 0..1000 on a stretched 1000-square canvas; frames are scene-local, integers, and each end must be >= start. Use #RRGGBB colors. Elements paint in order: paths draw on; filled polygons, rectangles, circles and text fade in and stay. marker:true shows a moving dot on a path during its animation, not an eraser or pen image. Path erase:true erases only that path, not other elements. Split removable lines into separate paths. No arbitrary code, image input, automatic texture or moving tool is available.

A drawing replaces the scene layout. Required visible labels must be native drawing.elements with type:"text" and the exact requested words; copy.headline and lower_third are not rendered on this path. Keep narration-only disclosures in narration. Never blank a headline with "" or whitespace: any present headline must be nonblank. Remove unwanted layout copy with whole-object copy:null; for a text-free layout shell use layout:"list" with copy:null, then keep the drawing and narration intact. Omit copy when no copy edit is intended. To preserve selected layout-copy fields, clear the object and restore only the supported wanted fields in a second edit.

Increasing y points downward. Paths and markers travel from the first point to the last; upward flow needs decreasing y. Put an arrowhead at the final endpoint, pointing in the same direction as the final segment. Check the entire physical chain (source, connector, destination) rather than relying on an arrow label to imply direction.

For continuation, finish all source animation by its last frame and end marker paths before that frame. Set source_scene_id only when copying into a different scene without a drawing; use the latest preceding diagram scene containing all changes to retain, not an older base that drops intervening steps. For example, reservoir → wick → roots must extend the wick scene for the roots view so the full reservoir-to-wick-to-soil chain persists. Inherited visible elements start fully drawn at frame 0, erased paths are omitted. storyboard.inspect_drawing returns zero-based source indices: remove removes an element instantly; erase animates a copied path only. Omit source_scene_id to append to the same scene. The result must contain 1–120 elements total. Hold the final state; inspect early, middle, final and cut frames when visual review is available.

Example (scene s1 has 100 frames): storyboard.draw {"scene_id":"s1","drawing":{"background":"#ffffff","elements":[{"type":"path","points":[[100,100],[300,100]],"color":"#222222","width":3,"start":0,"end":30,"marker":true}]}}. Continue with storyboard.extend_drawing {"scene_id":"s2","source_scene_id":"s1","elements":[{"type":"circle","x":300,"y":100,"radius":12,"color":"#cc4400","start":10,"end":20}]}.

Design actual subject geometry before labels. For solid objects use back walls, top planes, darker vertical faces, contours and details; individual stair treads need risers. Honor the requested medium and contrast with authored strokes and planes. Native drawings and mixed-layout packages need no minimum SVG count. Complete the requested scenes and required referenced assets; plan a still only when the brief calls for one.
