Behind the work

Open weights, honest credits

comfyrizz uses open-weight models: FLUX Klein for stills and LTX for motion. Experimental workflows can also use MiniMax FastH3 Omni for video and audio, under the MiniMax-H3 Community License. No closed video model sits in the pipeline.

Judge demos run on Comfy Cloud using credits provided for the event. Access is an invite-only, tokenized workspace hosted separately from this site.
